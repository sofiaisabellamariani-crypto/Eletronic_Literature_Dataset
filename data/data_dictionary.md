# Data Dictionary – Electronic Literature Dataset

This document defines the columns used in the dataset and explains their meaning.

| Column | Description | Allowed / Example Values |
|------|------------|--------------------------|
| **ID** | Unique identifier for each work | ELIT001, ELIT002 |
| **Title** | Title of the work | Free text |
| **Creator** | Author or collective responsible for the work | Personal name, collective name |
| **Original_Date_Published** | Year of first publication | YYYY |
| **Original_Publisher** | Individual or institution that first published the work | Personal name, publisher, journal |
| **URL** | URL where the work is or its record can be accessed | Valid URL |
| **Access_Date** | Date of last access | YYYY-MM-DD |
| **Type** | Main form of electronic literature | hypertext, generative, interactive fiction, kinetic poetry, multimedia, other |
| **Genre** | Literary genre of the work | poetry, fiction, documentary, essay, narrative, memoire, hybrid |
| **Software_Dependencies** | Required software or plugins | Flash Plugin, Shockwave, QuickTime, Web Browser |
| **Computer_Language** | Programming or markup languages used | HTML, CSS, JavaScript, XHTML, Not stated |
| **Authoring_Platform** | Platform or tool used to create the work | Flash, Storyspace, Prezi, Director, Not stated |
| **Interaction_Level** | Degree of reader interaction | none, low, medium, high |
| **Textuality** | Textual structure of the work | linear, non-linear, modular, database-like |
| **Versioning** | Information about versions of the work | stable, updated, multiple versions, unclear |
| **Language** | Language(s) of the work | English, Spanish, Portuguese, etc. |
| **Metadata_source** | Source of metadata information | ELO directory, official website, archive record |
| **Preservation_status** | Current accessibility status | live, archived, partially broken, inaccessible |
| **L-icense** | License under which the work is distributed | CC BY-NC-ND, not stated |
| **Short_Description** | Short description of the work | Max 200 characters |
